# The Fractured Way

**The Fractured Way** is a 3D parkour platformer currently in development using Unreal Engine 5.8.

This repository documents the game's ongoing development, technical improvements, gameplay systems, and future demo releases.

## About the Game

The Fractured Way is a multi-level, third-person parkour game focused on fluid movement, environmental hazards, survival, and atmospheric level design.

Players navigate distinct environments connected through a central hub, with each level introducing unique traversal challenges, environmental obstacles, and visual themes.

The game features an interconnected dimension controlled by a mysterious entity known as Hatred, challenging players to survive and find their way out.

## Features

- Third-person parkour movement
- Sprinting, wall-running, mantling, sliding, and dodging
- Stamina management and movement animations
- Checkpoint and respawn systems
- Autosave, continue functionality, and six manual save slots
- Central hub with level progression
- Multiple environments with unique traversal challenges
- Dynamic environmental hazards and moving platforms
- Chaos physics-based projectile destruction and explosive debris
- Custom C++ projectile spawning and collision systems
- Niagara visual effects and particle systems
- Dynamic lightning, rain, and storm systems
- Physics-based ragdoll death and knockback
- Custom protagonist with skeletal rigging and animations
- Custom menus, settings, and UI
- Performance-optimized environmental assets and rendering
- Blueprint and C++ gameplay systems
